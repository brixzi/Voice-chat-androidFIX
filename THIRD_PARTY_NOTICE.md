# Third-party attribution

This experimental Forge client-side port is based on the **mechanism** of
VoiceChat Android Fix by melon4ik666:
https://github.com/melon4ik666/voicechat-android-fix

The GitHub Actions build fetches **unmodified, precompiled** AArch64 Android
native libraries from a pinned upstream commit and verifies exact Git blob IDs.
These third-party binaries are **not** included in this source ZIP and have
**not** been independently audited or runtime-tested here. Please review
source code, build provenance, and relevant licenses before public distribution.

Simple Voice Chat (henkelmax) is separate proprietary-copyrighted software and
is not included in this project. The native wrapper libraries are associated
with the separate projects opus4j, rnnoise4j, speex4j, lame4j.
